# ThreadCrew 使用指南

[English](USER_GUIDE.md)

## 窗口

- **左边：侧栏。** 你的群和 **新建群聊**。底部依次是 **桌面通知**、**已归档的群**、**设置与关于**、
  **退出 ThreadCrew**，以及浅色、深色主题和语言切换（默认英文，可以切换成中文）。
- **上面：群的顶栏。** 点群名打开群设置面板：群说明、导出、改名、归档。
  开工期间，旁边会显示协作任务和剩余额度。有事情等你处理时，会出现 **需要你处理** 的提示。
  放大镜用来搜索本群，右边两个成员按钮显示 Codex 和 Claude 的状态。
- **中间：聊天记录。** 你的消息在右边，代理的回复在左边。
- **下面：输入框。** 选择发给谁、**让他们讨论**、**开工**、附件和发送按钮。
  下面一行显示本群现在是「讨论」还是「开工中」。

## 连接会话

每个群有一个 Claude Code 席位和一个 Codex 席位。

1. 新群里，点代理卡片上的 **复制进群口令**。已有的群里，点顶栏上代理的名字，在菜单里复制。
2. 把口令贴到你想用的那个原生会话里。它会先读代理协议，然后自己进群。
3. 想把席位换到另一个会话时，在同一个菜单里点 **复制换会话的进群口令**，贴到新会话里。

一个会话同一时间只在一个群里。如果会话说口令过期了（`GATE_CHANGED`），
说明群的状态刚变过，重新复制一次口令就行。

开工期间，只有在你的电脑上确认过可行之后，才会自动唤醒 Codex；在那之前，
它会在下一次自己检查时再取工作请求。

成员按钮上的状态：

| 状态 | 意思 |
|---|---|
| 未进群 | 这个席位还没有会话。消息会先保存，等有会话进群后再送达。 |
| 已连接 / 待命 | 可以接收。Claude 在等消息时显示「待命」。 |
| 已通知 | 有消息在等它来取。 |
| 工作中 | 它正在回复，新消息会排在后面。 |
| 待确认 | 不确定上一条有没有送到，看旁边的提示。 |
| 需重连 | 会话现在收不到消息。消息会先保存；看下面的「重新连接代理」。 |

### 重新连接代理

代理的会话有时会收不到消息，最常见的是代理的应用或电脑重启之后。这时，你打开的群顶部
会出现「Claude 需要重新连接」（或 Codex）的横幅，发给它的消息会先保存，等它回来再送达。

1. 点横幅上的 **复制重连口令**（代理的菜单里也有）。
2. 打开那个代理原来的会话，也就是之前在这个群里的那个对话，把口令贴进去。
3. 会话会先核对自己是不是原来那个，然后重新连上席位、开始收消息。群里确认它真的在收消息后，
   横幅才会消失。

横幅只出现在你打开的群里。你在群里时代理掉线，横幅会先等 45 秒，所以代理两次回复之间的
短暂停顿不会触发它。别的会话用这句口令会被拒绝。想把席位换到另一个会话，请用
**复制换会话的进群口令**。

## 发消息

- 默认发给两位。点输入框下面的名字可以去掉一位，或者输入 `@` 只发给一位。
- **Enter** 发送，**Shift+Enter** 换行。消息可以用 Markdown。
- 有消息在排队或正在处理、并且输入框是空的时，发送按钮会变成 **停止**。停止会取消还没送达的消息；
  已经在生成的回复，要到代理自己的应用里停。

## 回复和讨论

每条消息下面按代理分别显示送达状态：排队中、已送达、已领取、已回复。

新需求先讨论：代理会给出看法，不会直接动手改。你用自己的话明确同意之后，或者是在你已经批准的
范围里继续做，它们才会动手。**开工**（见下一节）会开一个有额度和期限、两位一起做的协作任务。
显示「开工中」并不等于别的事也批准了：开工期间新发的消息先讨论，除非你明确说，不会扩大正在做的任务。

**让他们讨论** 在输入框下面，和 **开工** 并排。讨论的是你最新发的那条消息：两位都回复后，
点这个按钮，选 1 到 3 轮，再点 **开始讨论**。每位先看对方的回复，再回应。轮数用完，
或者两位在同一轮都表示没有要补充的，讨论就结束；之后按钮会变成 **再讨论**。

还不能讨论时，按钮留在原处、变灰，点开会说明原因（比如还差一份回复，或者有代理收不到消息）。
讨论进行中，按钮显示当前轮数；弹层里的 **停止** 会停下整个群，所以会先确认。

## 开工

需要两位一起干活、动手改东西时，发送前打开 **开工**，然后设置：

- **目标**：一句话，默认取消息的第一行；
- **额度**：小、标准或大，对应一定数量的请求和唤醒；
- **有效期**：2、4 或 10 小时。

两位都要在群里，一个群同一时间只能有一项协作任务。开工期间，它们会互相发请求（要对方做事或审查）
和答复，并汇报进度。

**按这个方案开工。** 讨论出你认可的方案后，鼠标指到那条代理回复上，点 **按这个方案开工**。
这条回复的全文（不是预览）会放进输入框，同时打开开工，目标取它的第一行。检查一下两者，
再按 **开工**；在那之前什么都不会发出。它只用你选的这一条：再选另一条会替换掉前一条；
输入框里原有的草稿，要你确认后才会被替换。超过一条消息上限（32,000 字）的回复不能这样用。

- **请求**：一位代理找另一位要东西。
- **唤醒**：让代理的会话处理一次请求或答复。一个请求加上它的答复通常要唤醒两次，
  所以预设的唤醒数是请求数的两倍。
- 顶栏显示两者的剩余量，旁边的 **＋** 可以追加。任何一项用完，任务都会暂停，等你追加。
- **停止** 会取消还没送达的消息；已经在生成的回复，要到代理自己的应用里停。
  停止后，协作任务面板里会出现 **解除这项任务**，用来释放这个群。

## 附件

点回形针、把文件拖进聊天区域，或者直接粘贴截图。支持 PNG、JPEG、WebP、PDF、TXT、MD、CSV、JSON、LOG，
每个最大 10 MB，每条消息最多 20 个。

文件一加进来就开始上传，显示在输入框上方。所有文件都传完才能发送；传失败的文件要先重试或移除，
所以不会出现你加了文件、消息却没带上的情况。代理收到的是本地文件副本，可以用它们自己的工具打开。
在聊天记录里，图片显示为缩略图，点开能看大图；其他文件点一下就下载。

代理能不能读懂 PDF 或图片里的内容，取决于它自己的工具。ThreadCrew 只负责把文件交给代理，
不会替代理安装读取或渲染工具。比如 Claude Code 用 Poppler（`pdftoppm`）把 PDF 页面渲染成图；
没装 Poppler 时，代理可能还能读出 PDF 的文字，但看不到版面。我们在 Windows 11 上测试时，
两个代理都读出了 PDF 的文字；PDF 页面渲染和版面复杂的 PDF 没有验证。

## 群说明

打开群设置面板，点 **写群说明**。群说明是纯文本，最多 8000 字，写项目是什么、有哪些约定、
要注意什么。新进群的会话会先读到当前的群说明，平时的消息也会把它作为背景带上。
群说明只是背景，不算新任务。

## 搜索、导出和翻看

- **搜索**（放大镜）按你输入的字面内容查找，不分大小写，最新的在前。点结果就跳过去。
- **导出为 Markdown**（群设置面板）会保存发言人、时间、完整内容和群说明。
  标题和标签跟随窗口语言；聊天内容按原文导出。附件只列出名字和大小，不包含文件本身。
- 聊天很长时，左边那排淡淡的刻度是你发的消息：鼠标指上去能预览，点一下就跳过去。
  **目录** 按钮列出全部。右下角的圆按钮可以跳到开头或回到最新。

## 已归档的群

一个群用完后，可以在群设置面板里归档。侧栏的 **已归档的群** 会把列表切换到归档，可以按群名筛选。
归档的群可以查看和恢复，但不能再发新消息。

## 设置与关于

**设置与关于** 里可以改你的显示名：群里和导出的记录里用这个名字显示你，留空就显示「你」。
这里还有版本号和许可证。**复制诊断信息** 会复制一段简短的技术信息，方便反馈问题：
包括产品和 Node 的版本、系统平台和检查结果，不含凭证、路径或会话 ID。

## 退出 ThreadCrew

关掉窗口时，ThreadCrew 会在后台继续运行。代理要继续收消息，还需要它们自己的会话开着并保持连接；
关掉代理的应用不在此列。要停止 ThreadCrew，用侧栏的 **退出 ThreadCrew**（**设置与关于** 里也有）。

退出会停下所有群，不只是打开的这个。确认框会列出还没处理完的事（还没送达的消息、
正在回复的、进行中的协作任务），并提醒这个窗口里还没发出的文字和附件。点 **取消** 什么都不会变。

确认后，窗口会显示 **正在退出 ThreadCrew…**，直到 ThreadCrew 给出结果：

- **ThreadCrew 已停止。** 可以关掉窗口。已保存的消息和任务记录都在；要再用时，从快捷方式重新打开。
  排队的消息会等到那时再送达；协作任务只在原来的授权还有效时继续，期限照常计时；
  不确定是否送到的不会自动重发。
- **ThreadCrew 没能正常停止。** 它可能还在运行。从快捷方式重新打开，启动器会核实并安全恢复。
  不要删除它的运行数据。
- **没能确认已经停止。** ThreadCrew 回应之前连接就断了，所以不能确定它有没有停。
  从快捷方式重新打开，启动器会核实它是否还在运行。

其他打开着的 ThreadCrew 窗口会显示同样的结果。代理自己的会话不会被关掉。

## 遇到问题时

- **窗口提示凭证失效**：服务重启过，刷新页面就好。
- **重启后代理一直显示需重连或连接断开**：打开那个群，用横幅（或代理菜单）里的 **复制重连口令**，
  贴回那个代理原来的会话。只有真要把席位换给另一个会话时，才用 **复制换会话的进群口令**。
- **某条消息显示待确认**：先到代理自己的应用里看一眼再决定要不要重发，它可能已经收到了。
